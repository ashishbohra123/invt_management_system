# Inventory Management System
Multi-portal inventory management with Express API, PostgreSQL, and 3 React frontends.
- Server (:3000), Admin Portal (:3001), Partner Portal (:3002), Customer Portal (:3003), PostgreSQL (:5432)
- Modules: Tenant, User, Product, Inventory, Order
- See scope/ for module dependency docs, docs/ for architecture, .env.example for config
